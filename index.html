Peak's Maven Repository

Maven repository browser

Automatically updates when new folders are pushed to GitHub.

How to use this repository

Add this to your project configuration to start using the plugins:

Gradle (Groovy)

repositories {
    maven { url "https://peaksuperior885.github.io/peaks_maven/files/" }
}

Gradle (Kotlin DSL)

repositories {
    maven(url = "https://peaksuperior885.github.io/peaks_maven/files/")
}

Maven

<repositories>
    <repository>
        <id>peak-repo</id>
        <url>https://peaksuperior885.github.io/peaks_maven/files/</url>
    </repository>
</repositories>
